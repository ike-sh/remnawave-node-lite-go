# v1.2.0

对齐官方 `@remnawave/node` v3.1.1，Panel 上报 `nodeVersion=3.1.1`。

## 主要变化

- rw-core 基线升级至 v26.7.28。
- 支持 Panel 下发自定义 core：HTTPS 下载、SHA-256 校验、原子激活和 stock 回滚。
- 支持启动前下载 `geodata.assets`。
- 支持 `preStart.cleanupSockets`，仅删除真实 Unix socket。
- 支持 `torrentBlocker.webhookUrl` 异步报告。

## 升级

```bash
curl -fsSL https://raw.githubusercontent.com/ike-sh/remnawave-node-lite-go/main/scripts/upgrade.sh | sudo bash -s -- --yes --upgrade-xray
```

升级保留现有 `node.env`、数据目录和 stock rw-core。动态 core 与 marker 位于 `/usr/local/bin/xray-custom`、`/usr/local/bin/.rw-core.json`。
