# v1.3.0

对齐官方 `@remnawave/node` v3.3.2：Panel 上报 `nodeVersion=3.3.2`，wire contract v3.2.3，完整覆盖 27 条 REST 路由。

## 主要变化

- 新增由 Secret Key 派生的私有 SNI，并将外部监听最低协议收紧到 TLS 1.3。
- 启动时严格验证 CA、节点证书、节点私钥和 JWT 公钥。
- 新增 `/node/stats/get-geocheck`，安装脚本同步部署官方 GeoCheck v0.3.0。
- 支持 `torrentBlocker.rulePlacement` 及位置变更后的 core 生命周期更新。
- 新增 Linux 重复实例检测与 `doctor` GeoCheck/SNI 自检。
- Release 构建固定使用 Go 1.26.6 或更高补丁版，并通过 `govulncheck` 可达路径扫描。
- rw-core 基线保持 v26.7.28。

## 兼容性提示

私有 SNI 是上游 3.3.x 的握手协议变化。升级 Node 前，请先确认 Panel 已升级到与 `@remnawave/node` 3.3.2 兼容的版本。旧 Panel 无法连接本版 Node。

## 升级

```bash
curl -fsSL https://raw.githubusercontent.com/ike-sh/remnawave-node-lite-go/main/scripts/upgrade.sh | sudo bash -s -- --yes
sudo remnanode-lite doctor
```

升级保留现有 `node.env`、数据目录和 rw-core，并安装 `/usr/local/bin/geocheck`。如需同时刷新 rw-core，增加 `--upgrade-xray`。
